# AI Chatbot

A Java-based Artificial Intelligence Chatbot with GUI, NLP,
MySQL database and rule-based response generation.

## Features

- User Registration
- User Login
- Chatbot GUI
- Basic NLP processing
- Intent detection
- Rule-based responses
- MySQL database
- Chat history
- Admin panel
- OOP implementation

## Technologies

- Java
- Java Swing
- MySQL
- JDBC
- Maven
- Git/GitHub

## Project Structure

- gui → User interface
- chatbot → Chatbot logic
- model → Data classes
- database → Database operations
- utils → Helper classes

## How to Run

1. Install Java JDK.
2. Install MySQL.
3. Create the chatbot database.
4. Run `database/chatbot.sql`.
5. Change MySQL password in `DatabaseConnection.java`.
6. Open the project in IntelliJ IDEA or VS Code.
7. Run `Main.java`.
